## Git and GitHub rules

- No commit, pull request or change description sent to GitHub may carry any attribution to Claude. No `Co-Authored-By` trailers, no "Generated with Claude Code" lines, no mention of Claude or AI authorship.
- All commit messages are written in English.
- Every new feature gets its own branch. Do not commit feature work directly to `main`.
- Within a feature branch, make a separate commit for each characteristic implemented, so the branch history reads as the list of what the feature does.
